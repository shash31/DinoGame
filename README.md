# Dino game

Basic dino game with clouds, rocks, cactuses and moon made with canvas element in JS

## To-Dos/Potential upcoming features:
- Progress from daytime to nighttime (switching between moon and sun)
- Using better images to add more variation to clouds and cactuses
- Adding crouch and birds maybe
- Speeding up over time
- High scores and leaderboard tracking
- Custom images and assets
- Customizable game constants/features(jump speed, gravity, speed, etc.)
